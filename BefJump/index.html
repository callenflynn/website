🎯 How to Play

  1. Click "Play on Befunge Playground" above
  2. Copy the Befunge code using the button below
  3. Paste it into the online interpreter
  4. Click "Run" to start the game
  5. Press any key to make the cube [@] jump!
  6. Avoid obstacles [#] and try to get a high score!

⚙️ Game Features

  • 🟥 Red cube player that jumps
  • 🟦 Cyan obstacles to avoid
  • 📊 Live score counter
  • 🎮 Simple one-key controls
  • 💥 Collision detection
  • 🔄 Game over and restart
  • 🧮 100% pure Befunge code!

🔧 About Befunge

  • Esoteric 2D programming language
  • Code flows in different directions
  • Uses a stack for data storage
  • Commands are single characters
  • Created by Chris Pressey in 1993
  • Designed to be hard to compile

🎨 Game Controls

  • Any Key: Make cube jump
  • ESC: Quit game
  • R: Restart after game over

Symbols:

  • [@] = Player (jumping cube)
  • [#] = Obstacles to avoid
  • === = Ground level
